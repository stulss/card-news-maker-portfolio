📌 [버전 B] 상세 경력기술서 양식 (STAR 기법 기반)

카드툰 (Card News Maker) | 프론트엔드 개발자

2026.10 ~ 2026.11 · 개인 프로젝트 (기여도 100%)

[프로젝트 소개]
서버 인프라 비용과 개인정보 유출 위험을 원천 차단하기 위해, 이미지 업로드·보정·AI 연산·내보내기까지 전 과정을 브라우저 단에서 100% 완결하는 고성능 카드뉴스·포토툰 그래픽 웹 편집 도구

[담당 역할 및 주요 업무]

  • React 19 및 Konva.js 기반의 2D 캔버스 씬 그래프(Scene Graph) 렌더링 파이프라인 설계 및 구현
  • 브라우저 온디바이스 AI(WebAssembly + MODNet) 통합을 통한 무서버 배경 제거(누끼 따기) 구현
  • 불변 상태 기반 타임라인 Undo/Redo 엔진 및 디바운스 연속 액션 압축 로직 개발
  • 대용량 미디어 영속화를 위한 IndexedDB 캐싱 아키텍처 및 10장 캐러셀 덱 ZIP 일괄 내보내기 구축
  • 외부 네트워크 의존성 0건을 위한 자체 호스팅 폰트 도입 및 엄격한 CSP 보안 정책 수립
  • Oxlint, Vitest, Playwright E2E 테스트 및 GitHub Actions CI 빌드 자동화 구축

[핵심 문제 해결 및 성과 (STAR)]

1. Canvas 웹폰트 비동기 동기화로 렌더링 폴백 결함 해결

S/T: Canvas 엔진 특성상 브라우저에 선언된 웹폰트가 로드되기 전에 캔버스가 그려져 시스템 기본 폰트(Malgun Gothic)로 폴백되는 현상 발생.

A: 텍스트 레이어 생성 시 document.fonts.load()를 비동기 호출하고, 로드 완료 이벤트를 감지하여 Konva Stage를 정밀 리렌더링하는 동기화 훅 개발.

R: 폰트 유실률 0% 달성 및 10종의 한글 감성 폰트를 왜곡 없이 화면에 즉각 반영.

2. 불변 스냅샷 구조 확립으로 되돌리기(Undo) 객체 참조 오염 차단

S/T: 레이어 순서 변경 후 실행 취소(Ctrl+Z) 시 과거 스냅샷 데이터까지 함께 변경되는 치명적 버그 발생.

A: 원인을 인플레이스 객체 변경(zIndex 직접 수정)으로 분석하고, 모든 레이어 조작 코드를 순수 함수 기반의 불변 복사(Immutable Update)로 전면 리팩토링.

R: 무제한 단계의 정확한 Undo/Redo 보장 및 상태 예측 가능성 대폭 향상.

3. isReady 프로미스 게이트를 통한 캐러셀 배치 캡처 누락 방지

S/T: 최대 10장의 슬라이드를 순회하며 ZIP으로 일괄 압축할 때, 비동기 이미지 로딩 지연으로 일부 슬라이드가 빈 화면으로 캡처되는 결함 발생.

A: 캔버스 렌더러에 "이미지 로드 카운트 == 실제 노드 수"를 검증하는 isReady 프로미스 게이트를 구축하고, 내보내기 엔진이 이를 await 대기 후 캡처하도록 랑데부 동기화 적용.

R: 10장 연속 고해상도 ZIP 내보내기 시 캡처 누락 결함 0건 달성.

4. WebAssembly 온디바이스 AI 도입으로 서버 비용 0원 & 완벽한 프라이버시 달성

S/T: 이미지 배경 제거 기능을 위해 외부 유료 API를 사용할 경우 서버 비용과 이미지 전송에 따른 프라이버시 이슈 존재.

A: @huggingface/transformers와 MODNet 신경망을 동적 import로 구성하여 브라우저 로컬 WASM 환경에서 1536px 인물 사진 누끼 추출 구현.

R: 서버 운영비 0원 달성, 업로드 이미지 서버 전송 0건(완전한 클라이언트 격리) 실현.

5. 크로스 플랫폼 Pointer Events 통일로 모바일 터치 드래그 지원

S/T: HTML5 표준 Drag & Drop API가 모바일/태블릿 터치 환경에서 동작하지 않아 레이어 순서 변경 불가.

A: Pointer Events API(setPointerCapture, elementFromPoint)를 적용하고 CSS touch-action: none을 지정하여 마우스와 터치 제스처를 단일 핸들러로 통합.

R: 모바일, 태블릿, 데스크톱 모든 디바이스에서 부드러운 드래그앤드롭 정렬 지원.

  • 2D 캔버스 & 그래픽스 프로그래밍: Konva.js를 활용한 다중 레이어, 곡선 텍스트(Arc text), 외곽선 스트로크, 5대 블렌드 모드, 마그네틱 스냅 가이드 구현 능력 보유
  • 브라우저 온디바이스 AI & WASM: 서버리스 환경에서 WebAssembly 기반 머신러닝 모델(MODNet)을 브라우저 메모리에 탑재하고 동적 번들 분리를 통한 초기 로딩 최적화 역량
  • 고급 프론트엔드 상태 관리: 얕은 복사/깊은 복사 참조 무결성을 고려한 불변 스냅샷 타임라인(Undo/Redo) 설계 및 연속 입력 디바운스 병합 구현
  • 클라이언트 스토리지 아키텍처: localStorage의 5MB 쿼터 한계와 Blob URL 수명 주기 문제를 해결하기 위한 IndexedDB 기반 대용량 미디어 비동기 캐싱 및 세션 복원 파이프라인 구축
  • 보안 및 웹 표준 품질: 자체 호스팅 폰트 번들링으로 외부 트래킹 차단, 엄격한 Content Security Policy(CSP) 적용, Zod 기반 방어적 스키마 검증기 구현
  • 자동화된 테스트 및 배포 파이프라인: Oxlint, Vitest 단위 테스트, Playwright E2E 스모크 테스트, GitHub Actions CI를 결합한 무결점 릴리즈 프로세스 운영

## 🚀 빠른 실행 방법

1. **로컬 더블클릭 실행**:
   - `포트폴리오_실행하기.bat` 또는 바탕화면의 `카드툰_포트폴리오_열기.bat`을 더블클릭하면 브라우저에서 포트폴리오가 바로 열립니다.
   - `index.html`을 브라우저로 직접 열어도 외부 서버 없이 100% 정상 작동합니다.

2. **로컬 서버 실행 (선택 사항)**:
   ```bash
   npx serve .
   ```

## 🌟 포트폴리오 웹사이트의 핵심 기능

1. **라이브 에디터 임베드**: 실제 배포된 카드툰 웹앱(`https://card-news-maker-beige.vercel.app/`)을 화면 내에서 직접 체험 가능.
2. **미니 카드뉴스 캔버스 시뮬레이터 (Interactive Mini Canvas)**: 속보, 밈, 개발자 인사이트, 공지 등 템플릿과 색상을 선택하고 Canvas 2D로 실시간 렌더링된 카드뉴스를 바로 PNG로 다운로드.
3. **STAR 방식 8대 핵심 트러블슈팅**: 상황(S) - 목표(T) - 행동(A) - 결과(Result) - Insight 기반 문제 해결 기록.
4. **4대 아키텍처 벤토 그리드(Bento Grid)**: 100% 무서버 프라이버시(IndexedDB), Konva 통합 파이프라인, 불변 상태 되돌리기, WASM AI 배경 제거 & CSP.
5. **AI 협업 & 주도적 판단**: AI의 무분별한 제안을 거부하고 제품의 본질(1인 카드뉴스 제작)에 집중한 의사결정 기록.
6. **다크/라이트 모드 & 반응형 지원**: 모바일 화면부터 데스크탑 와이드까지 완벽 대응.
